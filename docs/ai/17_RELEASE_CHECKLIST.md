# Release Checklist

## Product
- [ ] MVP acceptance criteria checked.
- [ ] UI tested at desktop and mobile widths.
- [ ] All visible controls work.
- [ ] Loading, empty, error, stale, and partial states checked.
- [ ] Demo content clearly labelled.

## Engineering
- [ ] Lint passed or baseline failure documented.
- [ ] Typecheck passed or baseline failure documented.
- [ ] Unit/integration tests passed or failures documented.
- [ ] Production build passed or failure documented.
- [ ] No unexplained console errors.
- [ ] No secrets in source, client bundle, logs, or git history.
- [ ] Dependencies reviewed.
- [ ] Environment variables documented with fake examples only.

## Data and legal
- [ ] Sources and update cadence documented.
- [ ] Attribution and data licenses reviewed.
- [ ] Upstream license and notices preserved.
- [ ] Limitations and non-real-time sources clearly disclosed.
- [ ] External links are safe and functional.

## Portfolio
- [ ] README explains the product and the upstream fork.
- [ ] Architecture diagram matches implementation.
- [ ] Screenshots reflect actual current UI.
- [ ] Setup instructions tested by a fresh run where possible.
- [ ] Deployment URL and known limitations documented.
- [ ] Contributions are accurately attributed.

# Prompt — UI Redesign Only

Redesign the NusaWatch interface while preserving application behavior and data integrations.

Before editing, inspect the actual layout, design tokens, routing, existing components, and responsive rules. Propose the file-level plan first.

Visual target:
- Professional dark geospatial intelligence workspace.
- Deep navy/charcoal surfaces, restrained cyan/teal accent, readable typography.
- Clear hierarchy, compact but breathable data panels.
- Map remains useful and interactive.
- No fake live metrics, decorative-only controls, or misleading status labels.
- Accessible contrast, keyboard focus, labels, reduced-motion support, and mobile usability.

Do not:
- Replace the map engine without a demonstrated reason.
- rewrite API/data logic during a UI-only task.
- add buttons that do nothing.
- remove upstream attribution.
- invent event data to make the UI look populated.

Verify loading, error, empty, stale, and populated states. Report exact files changed and checks performed.

# Prompt — Plan One Task

Read project brief, agent rules, current task board, decision log, repository audit report, and the technical docs relevant to the requested task.

Before editing:
1. Restate the task and acceptance criteria.
2. Identify actual files/modules likely involved.
3. Identify existing functionality to reuse.
4. List risks and what is explicitly out of scope.
5. Propose the smallest implementation plan.

Do not edit files until the plan is coherent. If repository evidence is missing, inspect first. If the task conflicts with project decisions, explain the conflict and ask only if a decision is truly required.

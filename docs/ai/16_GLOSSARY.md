# Glossary

- **Adapter**: module that communicates with one upstream source.
- **Canonical event**: normalized representation used by the app regardless of upstream schema.
- **Data provenance**: information describing where data came from and how it was obtained.
- **Event time**: when the source says the event occurred.
- **Fetch time**: when NusaWatch retrieved the data.
- **Freshness**: whether retrieved data is recent enough under a documented rule.
- **MVP**: minimum viable product that proves the core workflow.
- **OSINT**: open-source intelligence; analysis of lawfully accessible public information.
- **Partial data**: response where some sources or fields are unavailable.
- **Source health**: whether an upstream source can currently be reached and parsed.
- **Stale data**: data older than the configured freshness threshold.
- **Vertical slice**: a small feature implemented end-to-end from data source to user interface.
- **Verified claim**: statement supported by actual repository code, official documentation, or observed test output.
